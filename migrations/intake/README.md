# מסלול הקבלה — קובצי הגירה

הקבצים כאן הם **העתק המקור** של מה שכבר קיים במסד החי, ונכתבו כדי שלא יהיה
קוד פרוס בלי עקבה — הכשל הרשום ב-PROJECT_GUIDE (96 פונקציות במסד, 4 ב-Git).

**אין להריץ אותם על המסד הקיים.** הם משקפים את מצבו, לא משנים אותו.
הם נועדו לשחזור, להשוואה, ולביקורת.

| קובץ | תוכן |
|---|---|
| `20260809_01_intake_tables.sql` | שתי הטבלאות, האינדקסים, ה-RLS וההרשאות |
| `20260809_02_intake_functions.sql` | שתים-עשרה הפונקציות, עם שלילת ההרשאות |
| `20260809_03_get_prompt_v2_intake_keys.sql` | הוספת intake ו-intake_decision לרשימת המשותפים |
